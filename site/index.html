One ambient inbox for your AI agent.

AgentBus is a TypeScript message bus that unifies Claude Code, Telegram, iMessage, email, and voice-memo webhooks into a single inbox/outbox — so an AI agent can hear from, and reply to, any of them without knowing which one it's talking to.

Quick start View on GitHub

Four processes, one HTTP boundary

Every adapter is a separate process that talks to the core over localhost HTTP — never by importing bus-core directly. That keeps each channel pluggable and independently restartable.

bus-core SQLite · message queue · inbound pipeline
claude-code-adapter MCP server over stdio
telegram-adapter Bot API, long-poll
bluebubbles-adapter iMessage, webhooks
email & pebble adapters IMAP · voice-memo webhook

What it does

Multi-channel by design

Claude Code (MCP), Telegram, iMessage/BlueBubbles, email, and Pebble Ring voice-memo webhooks all feed the same inbox.

Threaded, persistent memory

SQLite-backed thread store with transcript logging and summarization, so context survives across sessions and channels.

Slash commands

A command registry lets any channel trigger the same structured actions, no matter where the message came from.

Scheduling

Cron-like scheduled sends and reminders, built on the same pipeline as every other inbound/outbound message.

Channel relay & routing

Rewrite and re-submit a message from one channel to another with templated bodies — bounded hop count, full pipeline re-run.

Write your own adapter

Adapters only need to speak HTTP to bus-core. See the plugin authoring guide to add a new channel.

Quick start

npm install

cp config.yaml.example config.yaml
cp .env.example .env
# edit config.yaml and .env with your credentials

npx tsx src/index.ts        # run bus-core
npx tsx src/adapters/cc.ts   # run the Claude Code adapter

See the README for full configuration details, and docs/ for each adapter, the HTTP API, and the memory model.
