Talk to your Claude agent from wherever you are.

AgentBus connects the Claude Code agent on your computer to Telegram and email. Send it a message from your phone, and the answer comes back in the same chat.

What you can do

Your agent keeps running on your computer while you're away from it. Here's what that looks like in a normal day.

Text it from the train

Send a Telegram message from your phone. Your agent works on it at home, and the answer is waiting in the chat when you sit down.

Get a morning briefing

Set a schedule, such as 8:00 on weekdays, and your agent messages you first with whatever you asked for: the weather, your agenda, a summary of yesterday.

Ask for a reminder in plain words

"Remind me Thursday at 3 to call the dentist." The agent sets the reminder itself and messages you when it's time.

Keep topics apart

In a Telegram group with topics, each topic is its own conversation. Trip planning stays out of your work notes. Email works the same way: one conversation per thread.

Pick up where you left off

Come back to a conversation the next day and the agent still has the context. When a conversation goes quiet, it writes down what's worth keeping in its own notes, and reads them again later.

Send it a photo or a file

Share a photo of a receipt or a whiteboard, or a document, in Telegram. The agent gets the file and can work with it.

Where you can reach your agent

Use the ones that fit your day. Your agent replies in the place you wrote from.

  • Telegram

    Chat one-on-one, or use a group with topics to run several conversations side by side. You see what the agent is doing while it works.

  • Email

    Write to your agent's address and it answers in the same thread. Only people you list can reach it, and forged senders are dropped.

  • Siri on iPhone Early preview

    Ask Siri a question for your agent and hear the answer read aloud. For now, this needs a companion iPhone app that you build and install yourself.

  • Pebble Ring Extra setup

    Speak a quick voice note into the ring. It reaches your agent, which can pick it up in your Telegram chat.

A native Mac app is in development.

Stay in control

The agent works on its own, but you decide what it does and when it stops.

See it working

In Telegram, a status message lists each step as it happens, such as reading a file or searching the web. When the answer is ready, it replaces the status message.

Stop it at any time

Send /stop and the task it's working on ends right away. No half-finished answer arrives afterward.

Approve risky steps

When the agent needs permission for something, you get a Telegram message with Approve and Deny buttons. If no one answers within 15 minutes, the request expires. Available when your agent runs in full Claude Code sessions; the docs explain the setup.

Start fresh, and check the cost

Send /clear to start a new conversation. The agent saves notes from the old one first. Send /cost to see what it has spent today, this week and this month.

How it works

  1. AgentBus runs on your computer

    It sits next to Claude Code on a Mac or other computer that stays on. Your agent is Claude Code, with its own folder, instructions and skills.

  2. You connect the apps you want

    Add a Telegram bot, an email account, or both. You list the people who are allowed to talk to your agent.

  3. Messages go in, answers come back

    When you write, AgentBus hands the message to your agent along with the right conversation. The reply goes back to the chat or thread you wrote from.

Getting started

Setup takes some time in the terminal and a configuration file. The guide walks you through it one step at a time. You'll need:

  • Claude Code, installed and signed in.
  • A Mac or other computer that stays on, so your agent can answer while you're away.
  • Node.js 20 or later. The guide shows you how to check.
  • A Telegram bot or an email account for your agent, depending on how you want to reach it.
